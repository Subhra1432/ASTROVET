“Signal strength” (SNR and SDE) describes how noticeable the repeating pattern is; higher usually means clearer. A strong pattern is not proof of a planet. Transit time uses TESS’s time standard (BTJD).

Brightness over time

The plot shows measured brightness. Repeating downward dips are the events the searches examine.

The light-curve plot will appear after analysis. It shows how the star’s measured brightness changes and where repeating dips may occur.

Please remember: A repeating dip can have causes other than a planet. ASTROVET helps prioritize candidates for human review; it does not confirm planets.
