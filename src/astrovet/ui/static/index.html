What this review can tell you ASTROVET looks for repeated drops in a star’s brightness and checks whether the pattern resembles previously followed-up candidates. A low score does not prove that a planet is absent.
  • After analysis, this list will explain which checks were weak, disagreed, or could not run for this file.

1. Did we have enough clean data?

TESS measures a star’s brightness over time. Unreliable readings are removed and gaps are kept visible. If only a small part of the file is usable, the searches have less evidence to work with. Check the retained-reading count and file warnings.

2. Did the brightness drop repeat?

Two search methods look for repeating dips. Similar timing supports a repeating signal. Different timings, a weak signal, or too few clean readings make the result uncertain. A repeating signal can still come from something other than a planet.

3. Could another star or noise explain it?

An eclipsing pair of stars, stellar activity, or instrument effects can also make dips. Unequal alternating dips or another dip between transits are clues for review, not automatic proof of a false alarm.

4. How much planet-label training was available?

The encoder learned brightness patterns from 11,511 light curves without planet labels. The planet-like versus false-positive decision used 1,751 labeled events from targets selected for follow-up; its held-out check used 256 events. This is a small, selected sample compared with all TESS stars.

5. What do the scores mean?

The ASTROVET score ranks how closely the measurements match patterns learned from its labeled sample. The follow-up comparison score is calibrated for that selected sample. Neither number is the real-world chance that this star has a planet.

6. Why might a comparison say “Not available”?

The NASA comparison needs a matching catalog entry or a successful optional Docker run. The follow-up score needs the matching trained model and enough input measurements. A missing value means no comparison was produced; it is not evidence against a planet.

What to do next: open the brightness plot and detailed report, check the file-quality warnings and repeating-dip results, and ask a researcher to review uncertain or conflicting evidence. Only independent observations and scientific validation can establish whether a candidate is a planet.
